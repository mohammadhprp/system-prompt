# Code of Conduct

## Standard

Contributors are expected to be respectful, direct, and constructive. Disagreement is welcome when it improves the work. Personal attacks, harassment, and exclusionary behavior are not acceptable.

## Enforcement

Maintainers may remove comments, reject contributions, or limit participation when behavior harms the project. Reports should include links, context, and requested outcome.

## Scope

This standard applies to repository discussions, issues, pull requests, and community spaces connected to the project.
