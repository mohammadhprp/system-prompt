## Prerequisites

- **Node.js >= 18**

## Quick Start

### Install

```sh
npm install -g @mohammadhprp/system-prompt
```

### Run

```sh
system-prompt
```

The CLI walks you through selecting which skills, agents, commands, MCPs, and references to install, then wires everything into your project directory.
